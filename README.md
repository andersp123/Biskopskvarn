# Gulf-spel

Detta projekt är ett enkelt statiskt HTML-spel i [gulf.html](gulf.html).

## Starta spelet

1. Installera Python 3 om det inte redan finns.
2. Kör i mappen:

   ```bash
   python -m http.server 8000
   ```

3. Öppna sedan:

   http://localhost:8000

## Windows-snabbstart

Kör filen `serve_game.bat` i projektmappen för att starta en enkel lokal server.
